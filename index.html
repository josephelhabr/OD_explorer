About this explorer

Explore Texas city pairs using bidirectional weekday trips, road miles, and city populations. The on-roadway dataset opens automatically with 4,797 pairs and includes only pairs with at least 500 weekday trips. Use the dataset selector in Map Layers to switch to the original 55,088-pair dataset. Filters reset when switching datasets.

Filter and inspect

Search one city or fill both city boxes to find a pair in either endpoint order. Filter weekday trips by percentile, top/bottom N, or value range. Set road-mile and population ranges, or add conditions on the available attributes. Filters are combined with AND. Ranking follows the other filters; percentile thresholds include ties. Top/bottom N uses source order to break ties. Click a route or table row to inspect its attributes.

Population ranges can match either city, both cities, the smaller or larger city, or one endpoint. Smaller/larger comparisons require both populations. Missing values are excluded from an active numeric range. Range bounds are inclusive except when “Exclude the minimum value itself” is checked for road miles. The Over 50 mi shortcut sets distance strictly greater than 50. No distance or population cutoff is applied automatically.

Use Within the same urban area to include all pairs, exclude same-area pairs, or allow them only at or above a chosen road-mile minimum. Area matches use the supplied urban-area labels; 0, missing, and unassigned labels are not treated as shared areas. The exception minimum is inclusive: at 20 miles, a same-area pair with exactly 20 road miles is allowed. Other road-mile limits and all other filters still apply. Weekday trip ranking follows this exclusion.

Weekday trips use the supplied actual bidirectional count for each dataset. Both directions are already included. Reverse pairs are not merged, and weekday trip counts are not doubled. Population and road-mile values are read as supplied. Reset all restores the selected dataset; the on-roadway source does not contain pairs below 500 weekday trips.

Read the map

Color classes and value-scaled widths use the current filtered pairs and update whenever filters change. Choose quantiles, equal intervals, or natural breaks (Jenks). Jenks minimizes variation within classes using every filtered numeric value, including the frequency of duplicates. If there are fewer distinct values than the selected number of Jenks classes, fewer classes are used. A single value produces one class. Quantiles use interpolated thresholds; ties can produce unequal class sizes. Gray indicates a missing color value. City dots use the supplied city coordinates. The table and totals include all filtered pairs, including routes hidden with the layer checkbox.

Routes are simplified to the current zoom level for responsive display. Every supplied route vertex is retained for export, including all 2,528,163 vertices in the on-roadway dataset. Stored coordinates are rounded to seven decimal places. The supplied road-mile values are used for analysis.

Type an opacity from 0 to 100% or a base line width from 0.25 to 12 pixels, or use the paired sliders. Typed values and sliders remain synchronized. Width scaling, when enabled, uses the filtered color-field range.

Choose Single color · route overlap under Color by to give every route the same color and width. Pick a line color and reduce opacity, or use the 5% shortcut. Each pair contributes one line regardless of its weekday trip count. Brighter sections indicate more overlapping city-pair routes. Select a numeric attribute to restore the classified view.

Export

CSV includes the available attributes for every filtered pair. GeoJSON includes those attributes and every route vertex at seven-decimal coordinate precision. Both datasets export the supplied bidirectional weekday count as weekday_trips. Other retained attribute names and values stay as supplied. Spreadsheet formula-like text is escaped in CSV. Refreshing resets the filters and restores the on-roadway dataset.

Use on GitHub Pages

Upload the updated index.html and texas-roadway-01.bin to your GitHub Pages publishing folder. Keep the existing texas-od-01.bin and texas-od-02.bin for the original dataset. Data files can sit beside index.html or inside a data folder beside it. Open the tool through GitHub Pages or a local web server.

Use a current Chrome, Edge, Firefox, or Safari browser. Internet access is required for basemap tiles and the pinned Leaflet map library.
